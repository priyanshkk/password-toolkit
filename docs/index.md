# Password Toolkit documentation

Password Toolkit is a standard-library-only CLI for generating cryptographically
secure passwords and estimating their strength.

- [Architecture](architecture.md) - module layout, data flow and design decisions.
- [Usage](usage.md) - every command and flag, with example output.
- [README](../README.md) - installation, quick start and project overview.

The project supports Python 3.10 through 3.13 and has no runtime dependencies.
